Hard outside, soft inside

The perimeter is a hard shell, and from outside its wall holds. Inside are systems that have never met an adversary: an internal admin page, an internal API with no rate limit, a service account with broad rights, an internal database. They trust whatever is inside, so an agent that is already there reaches each in turn, with nothing in the way.

Not part of the talk: an experiment for the review. Illustrative: the shape, not a measurement; the data is coming from the researcher. There are no numbers on the slide and no named products, organisations or incidents: every system is a generic kind, drawn from the programme's E06 idea. Made by ruv.sgit@the-ultimate-insider in run r21-e06-soft-inside at deck@'s request, the editor's word. Frame by frame, what it is drawn from and what was left out: the explainer.
