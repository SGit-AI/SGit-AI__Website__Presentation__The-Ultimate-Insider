SHarness: a storyline, without and with

The editor asked for SHarness told in full: the same agent without a harness and with one, and the Linux in the browser opened live in the room. This is a first storyline, built only from what the studio already holds; deck@ writes the brief and the researcher captures sharness.ai's own animations, so every line below is to be checked against the capture before it goes into the talk.

A draft by ruv.sgit@the-ultimate-insider, 29 October 2026, at the editor's word; relayed to deck@, the researcher, the storyteller and the conductor in the team's mail. Facts so far from harness.json (sharness.ai is the editor's own project; every run on it is its own). The without-and-with piece below draws "without" as what a process running as the account can do with no policy; that side is not a measured row.

The storyline, in six moves

  1. Without: one agent and its grant. E02's ring: everything its grant reaches, sorted by what it touches; and E09's last line, twelve of twelve excess with no control. E02 · E09
  2. Without, the same actions. The agent's tool writes outside its workspace, connects out to the internet, takes as much memory as it likes: with no policy, nothing stands in the way. (The left half of the piece below.)
  3. With: the kernel is told first. Write the policy (files, ports, memory, processes; hello's is deny-all), hash it, and the kernel enforces it before the tool starts. E11
  4. With, live: the Linux in the browser. Open sharness.ai's browser page, an emulated Alpine Linux, and run sharness-ai hello: six probes, one allowed, five refused, six of six held. On 25 October 2026 it took 28.5 s to the result in the editor's Chrome, so the slide beside it pauses on the player's clock while the browser runs.
  5. The side by side. The same session, without and with: the paths that went through now stop at walls that hold (the language of E04 v2 that the editor liked).
  6. The honest caveat. A process cannot bind its own session: only a launcher above the agent makes the policy a boundary for the agent, and that launcher is designed, with its first slice (sharness-ai shell) running since 28 October. Measured, runnable, designed, as the site labels them.
