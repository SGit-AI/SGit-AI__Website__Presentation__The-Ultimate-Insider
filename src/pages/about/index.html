About this site, and a disclosure

The companion site for The ultimate insider, a talk by Dinis Cruz at hack::soho, hosted by IOActive in London on 29 October 2026. It holds the slides, the script, the sources and the articles written for the talk.

A participant disclosure

This site is published by the person giving the talk, and the way out it argues for runs through projects Dinis Cruz founded or works on: RiskMandate.ai, sgit.ai and The Cyber Boardroom. Read the second half of the talk with that in mind. The first half is built from public incidents and surveys, each linked on the sources page. This site is not published by IOActive, and the event details are from the event page as it was given in the brief.

How it is built

  • Static pages, built by one script. admin/build/build.py, standard library only, builds every page from src/ and content/, with the navigation and footer injected so they cannot drift.
  • Every page has a markdown twin at the same path ending in .md, and the site has an llms.txt, for agents.
  • The talk is data. talk.json holds every beat; the player, the script and the slide list all read it.
  • CI owns the version. Nobody types a version number. A push to dev or main runs one release job at a time, which picks the next number from the tags, commits and tags it as GitHub Actions, then builds and deploys that commit. The scheme is CI owns the version; the history is on releases.

What the gate checks

admin/build/validate.py fails the build on any of these, in CI before every release and again on the built site:

  • every internal link and image resolves against the built files;
  • every page has its .md twin and is listed in llms.txt;
  • no version placeholder survives the build;
  • no page loads a script or stylesheet from another host;
  • every script parses;
  • every beat of the talk has a slide, a title, a script and a planned length;
  • no em-dashes in prose;
  • the leak tripwire: private keys, cloud and API key shapes and sgit vault key shapes, in every tracked file and every built file.

Who builds it

Dinis Cruz, with AI agents. The first pass was built in one Claude Code session from the brief. A team of agents, each with a written mandate, in the shape of the SGit Newsroom and the PHP October 2026 newsroom, is next; its design will be published here before it runs.

What this site does not claim

  • The script is a draft from the article, written before rehearsal; the talk on the night will differ from it.
  • The demos slide lists candidates; the running order is confirmed on the night.
  • The licence and the autonomy ladder on the licence slide are examples, not a published scale.
  • The figures are the sources' figures, read as of the article (30 September 2026); none was re-measured here.
